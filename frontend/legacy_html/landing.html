What is the difference between SAP BTP and SAP ABAP?

SAP ABAP is SAP's core programming language used to customize and extend traditional SAP systems. SAP BTP (Business Technology Platform) is SAP's cloud platform for building new applications, integrations, and extensions on top of SAP and non-SAP systems. Many learners study ABAP first and add BTP as a cloud specialization.
